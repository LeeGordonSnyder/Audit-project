Data Source

SKU lookup data is loaded from data/skus.json in this app, bundled at deploy time. To update tag locations or exceptions, edit that file and push to GitHub — the live app updates automatically.

Audit Log Backend (optional)

Audit entries always save on this device (offline-safe). Optionally, also send each entry to a Google Sheet via a Google Apps Script Web App URL. See README for setup steps.

About

Installed as a home-screen app, this works fully offline for lookups and logging once loaded once. Audit entries queued for the Google Sheet sync automatically when back online.
